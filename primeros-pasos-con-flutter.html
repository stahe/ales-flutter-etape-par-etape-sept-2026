    3.1. Ejemplo 01: la estructura de una aplicación Flutter

    3.1.1. El proyecto

    Un proyecto [Flutter] se crea con el comando [flutter create]:

    1
    flutter create --org fr.stahe --platforms=android,web,windows my_application
    • [--org fr.stahe]: el prefijo del identificador de la aplicación, escrito al revés como un nombre de dominio. La aplicación [Android] se llamará [fr.stahe.my_application]; dos aplicaciones instaladas en el mismo teléfono deben tener identificadores diferentes;
    • [--platforms=...]: las plataformas de destino. Para cada una, [flutter create] crea una carpeta ([android/], [web/], [windows/], y también [ios/], [macos/], [linux/] si se solicitan): un pequeño proyecto específico de la plataforma que simplemente lanza el motor de [Flutter] y carga la aplicación en él. Rara vez se modifica (el nombre de la aplicación, el ícono y los permisos);
    • [my_application]: el nombre del proyecto, que también es el nombre del paquete [Dart]: letras minúsculas, números y guiones bajos.

    El comando genera una aplicación completa, lista para ejecutarse (un contador). El proyecto de ejemplos se creó de la misma manera y, luego, su carpeta [lib/] se completó manualmente para reunir veinticinco aplicaciones en un solo proyecto: así comparten los mismos paquetes, que se descargan una sola vez.

Para agregar un paquete, en lugar de editar el archivo manualmente, puede escribir [flutter pub add go_router]: el comando agrega la línea con la última versión del paquete.

    // =========================================================================
// lib/ex01_first_application/main.dart - una primera aplicación
// -------------------------------------------------------------------------
// Todo, en una aplicación Flutter, es un WIDGET: un objeto que describe
// una parte de la pantalla (un texto, un botón, un margen, una columna...).
// Los widgets se anidan unos dentro de otros y forman un ÁRBOL.
// Un widget tiene un método build(), que DEVUELVE los widgets que
// lo componen. Flutter llama a build() para producir la pantalla;
// LO LLAMA DE NUEVO cada vez que cambia el estado del widget (setState), y
// actualiza la pantalla con el nuevo resultado.
// =========================================================================

import 'package:flutter/material.dart';

// datos "ordinarios", fuera de los widgets: nunca cambian
const title = 'Welcome to Flutter';
const languages = ['Dart', 'Flutter', 'Material Design'];

// "12:05:09": la hora actual, con dos dígitos
String currentTime() {
  final d = DateTime.now();
  String twoDigits(int n) => n.toString().padLeft(2, '0');
  return '${twoDigits(d.hour)}:${twoDigits(d.minute)}:${twoDigits(d.second)}';
}

// el punto de entrada de todo programa Dart
void main() {
  // runApp: Flutter toma el control de la pantalla y muestra en ella el widget RAÍZ
  runApp(const Application());
}

// el widget raíz: configura la aplicación (título, tema, primera pantalla).
// StatelessWidget: un widget SIN estado, descrito por completo por sus parámetros
class Application extends StatelessWidget {
  const Application({super.key});

  @override
  Widget build(BuildContext context) {
    // MaterialApp: una aplicación con los colores y el comportamiento de
    // Material Design, el lenguaje visual de Google
    return MaterialApp(
      title: 'Example 01',
      // sin banner "DEBUG" en la esquina de la pantalla
      debugShowCheckedModeBanner: false,
      // los colores de toda la aplicación, derivados de un color base
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const HomePage(),
    );
  }
}

// un widget CON estado: consta de dos partes, el widget en sí (que nunca
// cambia) y un objeto State (que contiene los datos que cambian)
class HomePage extends StatefulWidget {
  const HomePage({super.key});

  @override
  State<HomePage> createState() => _HomePageState();
}

// el "_": esta clase es PRIVADA, invisible fuera de este archivo
class _HomePageState extends State<HomePage> {
  // el ESTADO: campos simples del objeto State
  int _counter = 0;
  String _time = currentTime();

  // la función a la que llama el botón
  void _increment() {
    // setState: el estado se modifica DENTRO de la función que se pasa a setState;
    // Flutter vuelve entonces a llamar a build() para actualizar la pantalla. Nunca
    // modificamos la pantalla nosotros mismos
    setState(() {
      _counter++;
      _time = currentTime();
    });
  }

  @override
  Widget build(BuildContext context) {
    // Scaffold: la estructura de una pantalla Material (barra superior, cuerpo...)
    return Scaffold(
      appBar: AppBar(title: const Text('Example 01 - a first application')),
      // Padding: un margen alrededor de su hijo
      body: Padding(
        padding: const EdgeInsets.all(16),
        // Column: hijos colocados uno debajo del otro
        child: Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text(title, style: Theme.of(context).textTheme.headlineSmall),
            const SizedBox(height: 12),
            const Text(
              'This screen is produced by Flutter, from the main function '
              'and the Application and HomePage widgets.',
            ),
            const SizedBox(height: 8),
            // ${expression} inserta el valor de una expresión en una cadena
            Text('It is written in ${languages.join(', ')} (${languages.length} languages).'),
            const SizedBox(height: 16),
            // onPressed: la función a la que se llama cuando se presiona el botón (ver ejemplo 04)
            FilledButton(onPressed: _increment, child: const Text('Click me')),
            const SizedBox(height: 16),
            Text(
              'You clicked $_counter times (last click: $_time).',
              style: const TextStyle(fontWeight: FontWeight.bold, color: Color(0xFF087EA4)),
            ),
          ],
        ),
      ),
    );
  }
}

    Empecemos por el final: el programa.

    • Línea 13: la biblioteca [Material] de [Flutter]: todos los widgets de [Material Design], el lenguaje visual de [Google] (botones, campos de entrada, barras, ventanas, etc.). Importa por sí misma el resto de [Flutter];
    • líneas 16–17: dos valores de datos ordinarios, declarados fuera de los widgets: nunca cambian. [const]: una constante conocida en tiempo de compilación;
    • líneas 20–23: una función ordinaria que devuelve la hora actual en el formato “12:05:09”. Contiene una pequeña función propia, [twoDigits], escrita en una sola línea con [=>];
    • líneas 27–29: la función [main], llamada al iniciar. [runApp] inicia [Flutter]: toma el control de la pantalla y muestra el widget que se le proporciona, la raíz de la aplicación.

    El widget raíz, [Application]:

    • Línea 34: un widget es una clase. Esta clase hereda de [StatelessWidget], un widget sin estado: lo que muestra depende únicamente de sus parámetros y nunca cambia por sí solo;
    • Línea 29: su constructor. [{super.key}]: un parámetro con nombre opcional que se pasa a la clase padre. Todos los widgets lo tienen: la “clave” que lo identifica (véase el ejemplo 04). El constructor es [const]: [Application()] puede ser una constante que [Flutter] nunca necesita reconstruir;
    • Líneas 38–47: el método [build], el núcleo de un widget. Devuelve los widgets que lo componen. [@override]: sobrescribe el método [build] de la clase padre. El parámetro [context] es la posición del widget en el árbol de widgets: sirve para recuperar lo que proporcionan sus ancestros (el tema, por ejemplo, línea 90);
    • líneas 41–47: [MaterialApp] es el widget que convierte un árbol de widgets en una aplicación [Material]: un título ([title], el nombre de la aplicación en la lista de aplicaciones recientes del teléfono o en la pestaña del navegador), un tema ([theme]) y una pantalla de inicio ([home]). [debugShowCheckedModeBanner: false] elimina el banner “DEBUG” que una aplicación en desarrollo muestra en una esquina. [ThemeData(colorSchemeSeed: Colors.indigo)]: todos los colores de la aplicación (botones, barras, campos, etc.) se derivan de un único color base, según las reglas de [Material Design] 3.

    La primera pantalla, [HomePage], tiene datos que cambian: es un widget con estado.

    • Líneas 54–58: un [StatefulWidget] consta de dos partes. El widget en sí, como cualquier widget, nunca cambia (sus campos serían [final]); su única tarea es crear, mediante [createState], un objeto [State], que a su vez contiene los datos que cambian. [Flutter] crea este objeto una sola vez y lo conserva mientras el widget permanezca en el mismo lugar del árbol;
    • línea 62: el objeto [State]. Su nombre comienza con un guion bajo: en [Dart], todo lo que comienza con [_] es privado e invisible fuera del archivo;
    • líneas 64–65: el estado: campos simples del objeto [State];
    • líneas 68–75: el método llamado por el botón. No afecta la pantalla: cambia el estado dentro de la función pasada a [setState]. [setState] ejecuta esta función y luego notifica a [Flutter] que el estado ha cambiado: [Flutter] llamará a [build], comparará el nuevo árbol de widgets con el anterior y volverá a dibujar lo que ha cambiado;
    • líneas 79–105: el [build] de la pantalla:
      • [Scaffold] (“andamio”) es la estructura de una pantalla [Material]: una barra superior ([appBar]), un cuerpo ([body]) y, si se solicitan, una barra inferior, un botón flotante y un menú lateral;
      • [AppBar]: la barra superior; su título es un widget ([Text]), como casi todo en [Flutter];
      • [Padding]: un margen alrededor de su único hijo, [child]. [EdgeInsets.all(16)]: 16 puntos en cada lado (un “punto” lógico, independiente de la densidad de pantalla: aproximadamente 2,6 píxeles en el teléfono de las capturas de pantalla);
      • [Column]: sus hijos, [children], dispuestos uno debajo del otro. [crossAxisAlignment: CrossAxisAlignment.start]: alineados a la izquierda (el eje “transversal” de una columna es el eje horizontal);
      • [Text]: texto. Su estilo puede derivarse del tema: [Theme.of(context).textTheme.headlineSmall] es el estilo para los “títulos pequeños”;
      • [SizedBox]: una caja vacía con una altura especificada, un espacio entre dos widgets;
      • línea 98: [${expression}] inserta el valor de una expresión en una cadena; [$_counter] basta para una variable simple (línea 104);
      • línea 101: un botón. [onPressed] recibe la función que se llamará cuando se presione el botón. Se especifica la función misma, sin paréntesis: [onPressed: _increment()] la llamaría de inmediato, durante la construcción de la pantalla;
      • líneas 104–105: texto que depende del estado. Cuando el estado cambia, se llama a [build] y este texto cambia.

    Dos notas sobre [Dart]:

    • casi todos los argumentos de los widgets son parámetros con nombre ([title: ...], [child: ...]): el árbol de widgets se lee como una descripción, y el orden de los argumentos no importa. Un parámetro con nombre es opcional, a menos que se declare como [required];
    • la palabra clave [const] antes de un widget ([const SizedBox(height: 12)]) lo crea una vez por todas en tiempo de compilación. [Flutter] sabe entonces que nunca cambia y no pierde tiempo comparándolo. El analizador señala cualquier [const] que se haya omitido; [VS Code] sabe agregarlos por sí solo.

class CalculatorPage extends StatefulWidget {
  const CalculatorPage({super.key});

  @override
  State<CalculatorPage> createState() => _CalculatorPageState();

class _CalculatorPageState extends State<CalculatorPage> {
  // el estado
  String _label = 'Pen';
  double _priceExclVat = 2.5;
  int _quantity = 1;
  double _vatRate = 20; // en %
  // el historial de los últimos 5 cambios del total con IVA incluido
  final List<String> _history = [];

  // un controlador da acceso al TEXTO de un campo de entrada: aquí necesitamos uno
  // para devolverlo a su valor inicial (Reset). El ejemplo 05
  // los estudia en detalle
  final _labelField = TextEditingController(text: 'Pen');
  final _priceField = TextEditingController(text: '2.5');

  // valores CALCULADOS: getters, recalculados en cada lectura
  double get _totalExclVat => _quantity * _priceExclVat;
  double get _vatAmount => _totalExclVat * _vatRate / 100;
  double get _totalInclVat => _totalExclVat + _vatAmount;

  // TODOS los cambios del estado pasan por este método: anota el
  // total con IVA antes del cambio, aplica el cambio y completa
  // el historial si el total ha cambiado
  void _change(void Function() change) {
    final oldTotal = _totalInclVat;
    setState(() {
      change();
      if (_totalInclVat != oldTotal) {
        _history.insert(0, '${euros.format(oldTotal)} -> ${euros.format(_totalInclVat)}');
        if (_history.length > 5) {
          _history.removeLast();
        }
      }
    });
  }

  // cambiar el artículo restablece la cantidad a 1: lo hacemos donde sabemos
  // POR QUÉ cambia el estado
  void _changeLabel(String newValue) {
    _change(() {
      _label = newValue;
      _quantity = 1;
    });
  }

  void _reset() {
    _change(() {
      _label = 'Pen';
      _priceExclVat = 2.5;
      _quantity = 1;
      _vatRate = 20;
    });
    _labelField.text = 'Pen';
    _priceField.text = '2.5';
  }

  // el objeto State desaparece (salimos de la pantalla): se liberan los controladores
  @override
  void dispose() {
    _labelField.dispose();
    _priceField.dispose();
    super.dispose();
  }

  @override
  Widget build(BuildContext context) {
    final totalStyle = Theme.of(context).textTheme.titleMedium!.copyWith(fontWeight: FontWeight.bold);

    // Title: el título de la aplicación SIGUE al estado, como todo lo demás
    return Title(

      color: Colors.indigo,
      child: Scaffold(

        // ListView: una columna que se desplaza si excede la altura de la pantalla
        body: ListView(

          children: [

              child: Padding(
                padding: const EdgeInsets.all(16),
                child: Column(
                  children: [
                    // onChanged: se llama en cada pulsación de tecla, con el nuevo texto
                    TextField(
                      controller: _labelField,
                      decoration: const InputDecoration(labelText: 'Item'),
                      onChanged: _changeLabel,
                    ),
                    TextField(
                      controller: _priceField,
                      decoration: const InputDecoration(labelText: 'Unit price excl. VAT'),
                      // el teclado numérico del teléfono, con el punto decimal
                      keyboardType: const TextInputType.numberWithOptions(decimal: true),
                      // tryParse: null si el texto no es un número; también se acepta una coma
                      onChanged: (text) => _change(() => _priceExclVat = double.tryParse(text.replaceAll(',', '.')) ?? 0),
                    ),
                    const SizedBox(height: 12),
                    Row(
                      children: [
                        const Expanded(child: Text('Quantity (back to 1 if the item changes)')),
                        IconButton(
                          icon: const Icon(Icons.remove),
                          // null: el botón está deshabilitado
                          onPressed: _quantity > 0 ? () => _change(() => _quantity--) : null,
                        ),
                        Text('$_quantity', style: totalStyle),
                        IconButton(icon: const Icon(Icons.add), onPressed: () => _change(() => _quantity++)),
                      ],
                    ),
                    const SizedBox(height: 8),
                    // botones de los que solo UNO está seleccionado: la tasa de IVA
                    SegmentedButton<double>(
                      segments: const [
                        ButtonSegment(value: 5.5, label: Text('5.5%')),
                        ButtonSegment(value: 10, label: Text('10%')),
                        ButtonSegment(value: 20, label: Text('20%')),
                      ],
                      selected: {_vatRate},
                      onSelectionChanged: (choice) => _change(() => _vatRate = choice.first),
                    ),
                    const SizedBox(height: 12),
                    OutlinedButton(onPressed: _reset, child: const Text('Reset')),
                  ],
                ),
              ),
            ),
            Card(
              child: Padding(
                padding: const EdgeInsets.all(16),
                child: Column(
                  crossAxisAlignment: CrossAxisAlignment.start,
                  children: [
                    Text('$_quantity x $_label', style: Theme.of(context).textTheme.titleLarge),
                    const Divider(),
                    _line('Total excl. VAT', euros.format(_totalExclVat)),
                    _line('VAT ($_vatRate%)', euros.format(_vatAmount)),
                    _line('Total incl. VAT', euros.format(_totalInclVat), style: totalStyle),
                  ],
                ),
              ),
            ),
            Card(
              child: Padding(
                padding: const EdgeInsets.all(16),
                child: Column(

        ),
      ),

      child: Row(
        children: [

//   - condition ? widgetA : widgetB  : lo mismo, en una expresión;

//                                      ("collection for");
//   - ...otherList                   : los elementos de otra lista,

import 'package:flutter/material.dart';
import 'package:flutter_svg/flutter_svg.dart';

// una "enumeración": los únicos valores posibles de una especialidad
enum Specialty { generalPractitioner, pediatrician, cardiologist }

// una clase de datos: sus campos son final, un objeto Doctor
// nunca cambia. El constructor "const" permite crear constantes con ella
class Doctor {
  final int id;
  final String title;
  final String firstName;
  final String lastName;
  final Specialty specialty;
  final bool available;

  const Doctor(this.id, this.title, this.firstName, this.lastName, this.specialty, this.available);
}

const doctors = [
  Doctor(1, 'Mme', 'Marie', 'PELISSIER', Specialty.generalPractitioner, true),
  Doctor(2, 'Mr', 'Paul', 'TATOU', Specialty.pediatrician, false),
  Doctor(3, 'Melle', 'Sophie', 'DUPONT', Specialty.cardiologist, true),
];

// "un valor entre varios, según un valor": una EXPRESIÓN switch.
// El compilador comprueba que se manejan todos los casos de la enumeración
String label(Specialty s) => switch (s) {
  Specialty.generalPractitioner => 'general practitioner',
  Specialty.pediatrician => 'pediatrician',
  Specialty.cardiologist => 'cardiologist',
};

  Specialty.pediatrician => const Icon(Icons.child_care, color: Colors.orange),
  Specialty.cardiologist => const Icon(Icons.favorite, color: Colors.red),

// lib/ex04_events/main.dart - reaccionar a las acciones del usuario
// -------------------------------------------------------------------------
// Un widget interactivo recibe como parámetros las FUNCIONES a las que debe llamar
// cuando ocurre algo ("callbacks"):
//   - onPressed: f                  : se llama a f al presionar (botones);
//   - onPressed: () => remove(t)    : una función anónima, para pasarle sus
//                                     propios argumentos;
//   - onChanged, onSubmitted...     : la función recibe un dato (el
//                                     texto, la casilla marcada...);
//   - GestureDetector               : agrega gestos (toque, pulsación larga,
//                                     doble toque, arrastre...) a
//                                     CUALQUIER widget;
//   - Dismissible                   : deslizar una fila para eliminarla,
//                                     el gesto típico de un celular.
// Para actuar sobre un campo de entrada desde el código (leer o borrar su
// texto, darle el foco), le asociamos un CONTROLADOR y un FocusNode.
// =========================================================================

import 'package:flutter/material.dart';
import 'package:flutter/services.dart';

class Task {
  final int id;
  final String label;
  bool done;

  Task(this.id, this.label, {this.done = false});
}

  runApp(
    MaterialApp(
      debugShowCheckedModeBanner: false,
      theme: ThemeData(colorSchemeSeed: Colors.indigo),
      home: const TasksPage(),
    ),
  );
}

class TasksPage extends StatefulWidget {
  const TasksPage({super.key});

  @override
  State<TasksPage> createState() => _TasksPageState();
}

class _TasksPageState extends State<TasksPage> {
  final List<Task> _tasks = [
    Task(1, 'Install Flutter', done: true),
    Task(2, 'Read the chapter on events'),
  ];
  final List<String> _log = [];
  // el controlador del campo: su texto (lectura, escritura);
  // el FocusNode: su foco (el cursor y el teclado del teléfono)
  final _field = TextEditingController();
  final _focus = FocusNode();
  // un campo del objeto State que NO se muestra: modificarlo
  // no requiere setState
  int _nextId = 3;

  @override
  void dispose() {
    _field.dispose();
    _focus.dispose();
    super.dispose();
  }

  void _trace(String message) {
    final t = TimeOfDay.now();
    _log.insert(0, '${t.format(context)} $message');
  }

  // lo llaman el botón Y la tecla Enter del teclado (onSubmitted)
  void _add() {
    final label = _field.text.trim();
    if (label.isEmpty) {
      return;
    }
    setState(() {
      _tasks.add(Task(_nextId++, label));
      _trace('added "$label"');
    });
    _field.clear();
    // el foco vuelve al campo: se puede escribir la siguiente tarea
    _focus.requestFocus();
  }

  void _toggle(Task task, bool done) {
    setState(() {
      task.done = done;
      _trace('"${task.label}": ${done ? 'done' : 'to do'}');
    });
  }

  void _remove(Task task, String how) {
    setState(() {
      _tasks.remove(task);
      _trace('removed "${task.label}" ($how)');
    });
  }

  // los detalles de un toque: su posición, relativa al widget tocado
  void _position(TapDownDetails details) {
    final p = details.localPosition;
    setState(() => _trace('tap at (${p.dx.round()}, ${p.dy.round()})'));
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Example 04 - the events')),
      body: ListView(
        padding: const EdgeInsets.all(16),
        children: [
          Row(
            children: [
              Expanded(
                // CallbackShortcuts: atajos de teclado (un teclado
                // físico: computadora, emulador, tableta); Esc borra el campo
                child: CallbackShortcuts(
                  bindings: {const SingleActivator(LogicalKeyboardKey.escape): _field.clear},
                  child: TextField(
                    controller: _field,
                    focusNode: _focus,
                    decoration: const InputDecoration(hintText: 'new task (Esc to clear)'),
                    // la tecla "Enter" del teclado del teléfono
                    textInputAction: TextInputAction.done,
                    onSubmitted: (_) => _add(),
                  ),
                ),
              ),
              const SizedBox(width: 8),
              FilledButton(onPressed: _add, child: const Text('Add')),
            ],
          ),
          const SizedBox(height: 12),
          for (final t in _tasks)
            // Dismissible: deslizar la fila hacia la izquierda la elimina.
            // key: la IDENTIDAD de la fila, para que Flutter sepa cuál
            // ha desaparecido (ver la explicación en el curso)
            Dismissible(
              key: ValueKey(t.id),
              direction: DismissDirection.endToStart,
              background: Container(
                color: Colors.red.shade100,
                alignment: Alignment.centerRight,
                padding: const EdgeInsets.only(right: 16),
                child: const Icon(Icons.delete),
              ),
              onDismissed: (_) => _remove(t, 'swipe'),
              child: CheckboxListTile(
                // la casilla está A LA IZQUIERDA, como en una lista de tareas
                controlAffinity: ListTileControlAffinity.leading,
                value: t.done,
                // la casilla pasa su nuevo valor (bool?, de ahí el "!")
                onChanged: (checked) => _toggle(t, checked!),
                title: Text(
                  t.label,
                  style: t.done ? const TextStyle(decoration: TextDecoration.lineThrough, color: Colors.grey) : null,
                ),
                // una función anónima: la tarea de ESTA fila como argumento
                secondary: IconButton(
                  icon: const Icon(Icons.delete_outline, color: Colors.red),
                  onPressed: () => _remove(t, 'button'),
                ),
              ),
            ),
          const SizedBox(height: 12),
          // GestureDetector: cualquier widget se vuelve sensible a los gestos
          GestureDetector(
            onTapDown: _position,
            onDoubleTap: () => setState(() => _trace('double tap')),
            onLongPress: () => setState(() => _trace('long press')),
            child: Container(
              height: 80,
              alignment: Alignment.center,
              decoration: BoxDecoration(color: const Color(0xFFE7F5FF), borderRadius: BorderRadius.circular(8)),
              child: const Text('Touch this area (tap, double tap, long press)'),
            ),
          ),
          const SizedBox(height: 16),
          Text('Log', style: Theme.of(context).textTheme.titleSmall),
          for (final line in _log) Text(line, style: const TextStyle(fontSize: 12)),

      ),

// lib/ex06_reducer/main.dart - un formulario, un objeto, un reducer
// -------------------------------------------------------------------------
// El ejemplo 05 tenía un campo de estado por cada campo del formulario. Para un
// formulario real, preferimos UN objeto que contenga todos los valores, el
// MODELO (aquí un objeto Profile, no modificable), y describimos sus
// cambios en una sola función, el REDUCER:
//
//     reducer(currentState, action) -> newState
//
// El widget ya no modifica el estado: DESCRIBE lo ocurrido, con un objeto
// ProfileAction (Edit(Field.lastName, 'Dupont'), Leave(Field.lastName)...), y
// el reducer deduce de él el nuevo estado. Toda la lógica está en un
// solo lugar, en una función PURA (misma entrada, misma salida, sin efecto
// secundario), fácil de probar.
// Dart se presta bien a esto: una clase "sealed" enumera todas las acciones
// posibles, y un switch sobre una acción lo verifica el compilador
// (un caso olvidado es un error).
//
// El estado también guarda, por cada campo, si ha sido "tocado" (abandonado al
// menos una vez); de ahí deducimos si está "modificado" (su valor difiere del
// valor inicial) y si está deshabilitado.
// =========================================================================

import 'dart:convert';

import 'package:flutter/material.dart';

// el nombre de cada campo del formulario
enum Field { title, firstName, lastName, age, newsletter, email, country, birthDate, presentation }

// los datos del formulario: un objeto NO MODIFICABLE (todos sus campos son
// final). Para "modificarlo", construimos uno nuevo (copyWith)
class Profile {
  final String title;
  final String firstName;
  final String lastName;
  final int age;
  final bool newsletter;
  final String email;
  final String country;
  final String birthDate;
  final String presentation;

  const Profile({
    required this.title,
    required this.firstName,
    required this.lastName,
    required this.age,
    required this.newsletter,
    required this.email,
    required this.country,
    required this.birthDate,
    required this.presentation,
  });

  // una copia, en la que se cambian algunos campos (los demás se conservan);
  // "??": el nuevo valor si se proporciona, de lo contrario el anterior
  Profile copyWith({
    String? title,
    String? firstName,
    String? lastName,
    int? age,
    bool? newsletter,
    String? email,
    String? country,
    String? birthDate,
    String? presentation,
  }) {
    return Profile(
      title: title ?? this.title,
      firstName: firstName ?? this.firstName,
      lastName: lastName ?? this.lastName,
      age: age ?? this.age,
      newsletter: newsletter ?? this.newsletter,
      email: email ?? this.email,
      country: country ?? this.country,
      birthDate: birthDate ?? this.birthDate,
      presentation: presentation ?? this.presentation,
    );
  }

  // el valor de un campo, designado por su nombre
  Object value(Field c) => switch (c) {
    Field.title => title,
    Field.firstName => firstName,
    Field.lastName => lastName,
    Field.age => age,
    Field.newsletter => newsletter,
    Field.email => email,
    Field.country => country,
    Field.birthDate => birthDate,
    Field.presentation => presentation,
  };

  // una copia en la que UN campo, designado por su nombre, tiene un nuevo valor
  Profile withField(Field c, Object v) => switch (c) {
    Field.title => copyWith(title: v as String),
    Field.firstName => copyWith(firstName: v as String),
    Field.lastName => copyWith(lastName: v as String),
    Field.age => copyWith(age: v as int),
    Field.newsletter => copyWith(newsletter: v as bool),
    Field.email => copyWith(email: v as String),
    Field.country => copyWith(country: v as String),
    Field.birthDate => copyWith(birthDate: v as String),
    Field.presentation => copyWith(presentation: v as String),
  };

  Map<String, Object> toJson() => {for (final c in Field.values) c.name: value(c)};
}

// el estado completo: los valores y los campos ya abandonados
class ProfileState {

// las acciones posibles. "sealed": no hay otras que las de
// este archivo, el compilador lo sabe
sealed class ProfileAction {
  const ProfileAction();
}

class Edit extends ProfileAction {
  final Field field;
  final Object value;
  const Edit(this.field, this.value);
}

class Leave extends ProfileAction {
  final Field field;
  const Leave(this.field);
}

class Uppercase extends ProfileAction {
  const Uppercase();
}

class Reset extends ProfileAction {
  const Reset();
}

// el reducer: NUNCA modifica el estado que recibe, devuelve uno nuevo.
// El switch "desestructura" cada acción: Edit(:final field, ...) lee
// sus campos en variables del mismo nombre
ProfileState reducer(ProfileState state, ProfileAction action) => switch (action) {
  Edit(:final field, :final value) => ProfileState(state.values.withField(field, value), state.touched),
  Leave(:final field) => ProfileState(state.values, {...state.touched, field}),
  Uppercase() => ProfileState(
    state.values.copyWith(firstName: state.values.firstName.toUpperCase(), lastName: state.values.lastName.toUpperCase()),
    state.touched,
  ),
  Reset() => const ProfileState(initial, {}),
};

class _ProfilePageState extends State<ProfilePage> {
  ProfileState _state = const ProfileState(initial, {});
  // un controlador por campo de texto; un "map": Field -> controlador
  final _controllers = {for (final c in textFields) c: TextEditingController(text: initial.value(c) as String)};

  @override
  void dispose() {
    for (final c in _controllers.values) {
      c.dispose();
    }
    super.dispose();
  }

  // LA única manera de cambiar el estado: describir lo ocurrido
  void _dispatch(ProfileAction action) {
    setState(() => _state = reducer(_state, action));
    // el reducer puede haber cambiado un texto (Uppercase, Reset): los
    // campos de entrada deben mostrarlo
    for (final MapEntry(key: field, value: controller) in _controllers.entries) {
      final value = _state.values.value(field) as String;
      if (controller.text != value) {
        controller.text = value;
      }
    }
  }

  Profile get _v => _state.values;

  // valores DEDUCIDOS del estado
  bool _modified(Field c) => _v.value(c) != initial.value(c);
  bool _disabled(Field c) => c == Field.email && !_v.newsletter; // el correo electrónico requiere el boletín informativo

        enabled: !_disabled(field),
        maxLines: lines,
        decoration: InputDecoration(labelText: label),
        onChanged: (text) => _dispatch(Edit(field, text)),
      ),
    );

import 'package:flutter/material.dart';

enum Field { title, firstName, lastName, login, password, confirmation }

// un "record": un pequeño grupo de valores con nombre, sin tener que escribir una clase
typedef Account = ({String title, String firstName, String lastName, String login, String password, String confirmation});

const titles = ['Mr', 'Mme', 'Melle'];
final loginFormat = RegExp(r'^[a-z0-9._-]{1,30}$');
const passwordMin = 6;

// las reglas: una función pura, que solo depende de su argumento.
// Devuelve, por cada campo con error, su mensaje
Map<Field, String> validate(Account c) {
  final errors = <Field, String>{};
  if (!titles.contains(c.title)) errors[Field.title] = 'Choose a title from the list.';
  if (c.firstName.trim().isEmpty) {
    errors[Field.firstName] = 'The first name is required.';
  } else if (c.firstName.length > 20) {
    errors[Field.firstName] = 'The first name must not exceed 20 characters.';
  }
  if (c.lastName.trim().isEmpty) {
    errors[Field.lastName] = 'The last name is required.';
  } else if (c.lastName.length > 20) {
    errors[Field.lastName] = 'The last name must not exceed 20 characters.';
  }
  if (c.login.isEmpty) {
    errors[Field.login] = 'The login is required.';
  } else if (!loginFormat.hasMatch(c.login)) {
    errors[Field.login] = 'Unaccented lower-case letters, digits, dot, hyphen, underscore.';
  }
  if (c.password.isEmpty) {
    errors[Field.password] = 'The password is required.';
  } else if (c.password.length < passwordMin) {
    errors[Field.password] = 'At least $passwordMin characters.';
  }
  // una regla que compara DOS campos
  if (c.confirmation != c.password) {
    errors[Field.confirmation] = 'The confirmation does not match the password.';
  }
  return errors;
}

// una franja horaria, tal como la describe la API de RdvMedecins
class Slot {
  final int startHour;
  final int startMinute;
  final int endHour;
  final int endMinute;

  const Slot(this.startHour, this.startMinute, this.endHour, this.endMinute);
}

enum Part { all, start, end }

// "8:05" en lugar de "8:5"
String _time(int h, int m) => '$h:${m.toString().padLeft(2, '0')}';

// un parámetro OPCIONAL, con su valor por defecto: [Part part = Part.all]
String timeRange(Slot c, [Part part = Part.all]) => switch (part) {
  Part.start => _time(c.startHour, c.startMinute),
  Part.end => _time(c.endHour, c.endMinute),
  Part.all => '${_time(c.startHour, c.startMinute)} - ${_time(c.endHour, c.endMinute)}',
};

// una EXTENSIÓN del tipo String: nuevos métodos para TODAS las cadenas
extension Formatting on String {
  // "marie pelissier" -> "Marie Pelissier"; \p{L}: una letra, con o sin acento
  String get capitalized => replaceAllMapped(
    RegExp(r'\p{L}+', unicode: true),
    (m) => m[0]![0].toUpperCase() + m[0]!.substring(1).toLowerCase(),
  );

  // "Marie PELISSIER" -> "MP"
  String get initials =>
      split(RegExp(r'\s+')).where((word) => word.isNotEmpty).map((word) => word[0].toUpperCase()).join();
}

// "2026-10-05" (el formato de la API de RdvMedecins) -> una fecha
DateTime toDate(String day) => DateTime.parse(day);
