    14. Apéndices

    14.1. Instalación de Flutter

    El SDK de [Flutter] se puede descargar de docs.flutter.dev (seleccione [Windows], luego [Android]). Es una simple carpeta comprimida, que se extrae en una carpeta SIN espacios ni caracteres acentuados (p. ej., [C:\dev\flutter]), y luego se agrega su subcarpeta [bin] a la variable de entorno del usuario [Path]. El SDK de [Dart] está incluido. Verifique la instalación en una consola nueva:

    1
2
    flutter --version
flutter doctor

    [flutter doctor] verifica todo lo que [Flutter] requiere: el SDK, [Android] y sus licencias, [Chrome], [Visual Studio] (para aplicaciones de [Windows]), los dispositivos conectados y el acceso a la red. Cada línea va precedida de una marca de verificación [√] si todo está bien, una X [X] o un signo de exclamación [!] en caso contrario, con instrucciones sobre qué hacer debajo. [flutter doctor -v] ofrece detalles (versiones, rutas).

    La línea “Visual Studio” solo se aplica a las aplicaciones de [Windows] (la carpeta de ejemplos [windows/] ): puede permanecer en error si solo se apunta a móviles y a la web.

    En [Windows], los proyectos que usan paquetes de código nativo ([shared_preferences]...) requieren el “modo de desarrollador” del sistema: [flutter pub get] lo indica (“Building with plugins requires symlink support”). Puede habilitarlo en Configuración / Sistema / Para desarrolladores (comando [start ms-settings:developers]).

    14.2. Instalación de Android Studio y de un emulador

    [Android Studio] se puede descargar desde developer.android.com/studio. No se usa para escribir código, sino para instalar el SDK de [Android] y crear un emulador:

    • En el primer inicio, el asistente instala el SDK de [Android];
    • menú More Actions / SDK Manager, pestaña SDK Tools: marque “Android SDK Command-line Tools”, que [Flutter] requiere;
    • en una consola: [flutter doctor --android-licenses], y acepte las licencias;
    • menú More Actions / Virtual Device Manager: cree un teléfono virtual (por ejemplo, un “Pixel”) con una imagen de sistema reciente. Haga clic en el botón ▶ para iniciarlo; [flutter devices] lo detectará entonces con el nombre [emulator-5554]. También puede iniciarlo sin abrir [Android Studio]: [flutter emulators] enumera los emuladores, y [flutter emulators --launch <name>] inicia uno.

    Para un teléfono real: en Configuración / Acerca del teléfono, tocar siete veces “Número de compilación” habilita las “Opciones de desarrollador”, donde puede activar la “Depuración por USB”. Al conectarlo a la computadora, el teléfono le pedirá que autorice la computadora; [flutter devices] lo detectará entonces.

    14.3. Instalación de Visual Studio Code

    [Visual Studio Code] se descarga de code.visualstudio.com. En el panel de extensiones (Ctrl-Shift-X), instale la extensión [Flutter] (de [Dart Code]), que también instala la extensión [Dart]. Ofrecen:

    • finalización de código, validación de código mientras se escribe (con las reglas de [analysis_options.yaml]), navegación a la definición de un widget o una clase, y renombrado en todo el proyecto;
    • formateo del código al guardar ([dart format]);
    • selección del dispositivo, en la esquina inferior derecha de la ventana (o el comando “Flutter: Select Device”);
    • inicio con F5 (depuración: puntos de interrupción, variables); cada vez que se guarda un archivo, la aplicación se recarga al vuelo;
    • acciones sobre widgets (Ctrl-. sobre un widget): “Wrap with Padding”, “Wrap with Column”, “Extract Widget”, etc.; muy útiles para reorganizar un árbol de widgets.

    Para ejecutar un ejemplo con F5, abra su archivo [main.dart] antes de presionar F5 (o cree un archivo llamado [.vscode/launch.json]). Abra un proyecto mediante el menú File / Open Folder (la carpeta [examples_flutter], por ejemplo), y abra una consola mediante el menú Terminal / New Terminal.

    14.4. La herramienta Flutter DevTools

    [Flutter DevTools] viene incluido con el SDK. Mientras la aplicación se ejecuta, [flutter run] muestra su dirección (“The Flutter DevTools debugger and profiler... is available at: http://127.0.0.1:9101... ”); en [VS Code], el comando “Flutter: Open DevTools” lo abre en el editor. Sus pestañas más útiles:

    • “Flutter Inspector”: el árbol de widgets de la pantalla y las propiedades de cada widget. “Select Widget Mode” permite tocar un elemento en el teléfono para encontrar su widget en el árbol; “Show Guidelines” dibuja los márgenes y las líneas de alineación. Esta es la herramienta que responde a la pregunta “¿Por qué este widget no está en el lugar correcto?”;
    • “Performance” y “CPU Profiler”: el tiempo dedicado a renderizar y dibujar cada fotograma, para identificar la causa de una animación entrecortada;
    • “Network”: las solicitudes HTTP de la aplicación, con sus encabezados y cuerpos; aquí se ve la cookie del token que se envía y se devuelve;
    • “Logging”: lo que muestra la aplicación ([debugPrint]).

    14.5. Instalación de Node.js

    [Node.js] se descarga de nodejs.org: seleccione la versión LTS (soporte a largo plazo). El instalador de [Windows] también instala [npm]. Solo es necesario para el servidor JSON. Verifique la instalación en una consola:

    1
2
    node --version
npm --version

    14.6. Instalación de MySQL con Laragon

    El servidor JSON requiere [MySQL] (o [MariaDB]). [Laragon] (laragon.org) instala uno en [Windows], listo para usar, con la herramienta de administración [HeidiSQL]. Después de la instalación:

    • el botón “Start All” inicia el servidor [MySQL] en el puerto 3306;
    • el usuario [root] no tiene contraseña: son los valores predeterminados del archivo [.env.example] del servidor;
    • en [HeidiSQL] (el botón “Database”), la opción de menú File / Run SQL File ejecuta el script [database/dbrdvmedecins2.sql].

    En [Linux] o [macOS], instale [MySQL] o [MariaDB] con el administrador de paquetes del sistema y ejecute el script con el cliente de línea de comandos: [mysql -u root -p < database/dbrdvmedecins2.sql].

    14.7. Instalación de curl

    [curl] viene incluido con [Windows] 10 y 11, [macOS], y con la mayoría de las distribuciones de [Linux]. Verifique su versión:

    1
    curl --version

    La opción [--json], utilizada en este documento, está disponible desde la versión 7.82 (2022). Si utiliza una versión anterior, reemplace [--json @file] por [-H "Content-Type: application/json" -d @file], o instale una versión reciente desde curl.se.

    En [PowerShell], debe escribir [curl.exe], no [curl]: en [PowerShell], [curl] es un alias de otro comando ([Invoke-WebRequest]), que no incluye las opciones de [curl]. El símbolo del sistema ([cmd]) no tiene este problema.
